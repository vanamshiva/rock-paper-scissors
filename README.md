# Rock Paper Scissors Game

A simple Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## How to Play

1. Choose one of the following options:
   - Rock
   - Paper
   - Scissors

2. The game will automatically select one of the options for the computer.

3. The winner is determined based on the rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock

4. The game will display the result and update the score for both the player and the computer.

## Installation

### Step 1: Clone the repository
```bash
git clone git@github.com:vanamshiva/rock-paper-scissors.git
```

### Step 2: Navigate to the project directory
```bash
cd rock-paper-scissors
```

### Step 3: Verify the files  
Run the following command to list the files in your project directory:

- **On Linux/macOS:**  
  ```bash
  ls
  ```
- **On Windows (Command Prompt or PowerShell):**  
  ```bash
  dir
  ```

---

## Running the Project  

### Step 4: Open the `index.html` file in your browser  
- **On Windows:**  
  ```bash
  start index.html
  ```
- **On macOS:**  
  ```bash
  open index.html
  ```
- **On Linux:**  
  ```bash
  xdg-open index.html
  ```

Alternatively, you can manually navigate to the project folder and double-click `index.html` to open it in a browser.
